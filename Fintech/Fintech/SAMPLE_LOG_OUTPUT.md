## How to Read Logs

1. **Opening a Log File**:
   ```powershell
   Get-Content "Logs\log-2026-06-08.txt" | more
   ```

2. **Filtering for Errors**:
   ```powershell
   Select-String '"LogLevel": "ERROR"' "Logs\log-2026-06-08.txt"
   ```

3. **Analyzing Performance**:
   ```powershell
   Select-String '"ExecutionTimeMs": (\d+)' "Logs\log-2026-06-08.txt" | 
     ForEach-Object { $_ -match '(\d+)'; [int]$matches[1] } |
     Measure-Object -Average -Maximum -Minimum
   ```
